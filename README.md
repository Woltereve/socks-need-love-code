C'est quoi ? Dating Soks est un site de rencontre... pour chaussettes dépareillées. Tu sais, celles que la machine a avalées, que tu as trouvées dans la rue, ou dont l'autre moitié a mystérieusement disparu.

Elles sont seules. Elles cherchent l'amour. Tu peux les aider. Le concept mélange l'esthétique de Tinder avec un annuaire de chaussettes célibataires — avec leur profil, leur histoire, et leurs critères de rencontre.
